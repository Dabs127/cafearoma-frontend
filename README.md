# Café Aroma WebApp

Una aplicación web full stack para mostrar productos, promociones y contacto de un negocio, con un panel de administración para gestionar productos y promociones.  
Soporta dos roles: **Usuario** y **Administrador**.

![Demo](https://github.com/user-attachments/assets/8f2b3069-7388-4df0-a72a-e1e871f4eaeb)

---

## 📦 Tecnologías y dependencias

### Frontend
- **Framework:** Next.js 15
- **UI:** TailwindCSS, React Icons
- **Formularios:** react-hook-form, zod, @hookform/resolvers
- **Internacionalización:** next-intl, i18next, react-i18next
- **Estado:** zustand
- **HTTP:** axios
- **Notificaciones:** sonner
- **Mapas:** mapbox-gl

---

## ⚡ Características principales

### Usuario
- Ver productos y promociones
- Registrarse para tener asi promociones exclusivas de cuentas registradas
- Contactar al negocio mediante formulario mandando email
- Ubicación en mapa interactivo

### Administrador
- Todo lo del usuario
- CRUD de productos
- CRUD de promociones
