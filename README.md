# Café Aroma WebApp

A full-stack web application to showcase products, promotions, and contact information for a business, with an admin panel to manage products and promotions.  
Supports two roles: **User** and **Administrator**.

![Demo](https://github.com/user-attachments/assets/8f2b3069-7388-4df0-a72a-e1e871f4eaeb)

---

## 📦 Technologies and Dependencies

### Frontend
- **Framework:** Next.js 15
- **UI:** TailwindCSS, React Icons
- **Forms:** react-hook-form, zod, @hookform/resolvers
- **Internationalization:** next-intl, i18next, react-i18next
- **State Management:** zustand
- **HTTP Requests:** axios
- **Notifications:** sonner
- **Maps:** mapbox-gl

---

## ⚡ Main Features

### User
- Browse products and promotions
- Register an account to access exclusive promotions
- Contact the business through a form that sends emails
- View the business location on an interactive map

### Administrator
- All features available to Users
- CRUD (Create, Read, Update, Delete) for products
- CRUD for promotions
